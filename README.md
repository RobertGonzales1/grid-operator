# Grid Operator — built web output

Play it: **https://robertgonzales1.github.io/grid-operator/**

This repo holds only the built site, served by GitHub Pages from
`main:/docs`. The source lives in a private repo (`grid-operator-dev`) and
deploys here via its `npm run deploy:web` — **do not edit anything here by
hand**, the next deploy overwrites it.

**Do not rename this repo.** The repo name is the play URL, and GitHub Pages
does not redirect on rename — the old address just dies.
